# product-showcase

## Skills

| Skill | Description |
|-------|-------------|
| `product-showcase-readme` | Write or revise a repository's main product README so prospective users understand the value and reach a first successful outcome |
| `product-showcase-pen-design` | Turn an approved README communication brief into an editable Pen design through concept agreement, multiple directions, selection, and verified export |

Scoped to the primary README of an application or developer tool — the value
proposition, first run, and supporting visual communication. Contributor-only
documentation and detailed reference material are a different job.

## Installation

Install these skills through the repository's `skills add` workflow documented
in the root README.
