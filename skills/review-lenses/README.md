# review-lenses

Shared finding policy and Lens definitions for review workflows. This group is
an internal dependency, not a standalone review procedure.

## Skill

| Skill | Description |
|---|---|
| [`review-lenses`](./review-lenses/SKILL.md) | Own the selection index, common finding policy, four baseline code Lenses, and artifact review Lenses |

Install this group alongside `quick-code-review` and `artifact-review`; both
review skills require it.

## Installation

Install this skill through the repository's `skills add` workflow documented in
the root README.
