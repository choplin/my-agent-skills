# lang-reference

Per-language conventions for this codebase: style, project layout, and tooling
preferences. One skill per language, with no shared base and no interaction
between them.

## Skills

| Skill | Description |
|-------|-------------|
| `lang-reference-go` | Error handling patterns, project layout, tooling, idiom |
| `lang-reference-java` | Coding style, project layout, tooling |
| `lang-reference-python` | Coding style, project layout, tooling |
| `lang-reference-rust` | Ownership and error handling, unsafe code, testing, Cargo tooling, workspace layout |
| `lang-reference-scala` | Coding style, project layout, tooling |
| `lang-reference-sql` | Structurally formatted, readable, explicit queries |
| `lang-reference-typescript` | Coding style, project layout, tooling |

None of these appear in the `/` menu. They apply from context while code in that
language is being written or reviewed.

## Installation

Install these skills through the repository's `skills add` workflow documented
in the root README.
