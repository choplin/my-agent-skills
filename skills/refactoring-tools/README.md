# refactoring-tools

## Skills

| Skill | Description |
|-------|-------------|
| `refactoring-tools-planner` | Analyze a repository and produce an implementation-ready `refactor-instructions.md` — a technical-debt map and a safe phased plan — without touching production code |

The deliverable is the plan. It is written to be handed to another coding agent,
with repository-specific validation, bounded changes, and explicit stop-and-ask
gates.

## Installation

Install these skills through the repository's `skills add` workflow documented
in the root README.
