# exec-plan

## Skills

| Skill | Description |
|-------|-------------|
| `exec-plan` | Run an ad-hoc task autonomously from a self-contained plan file, parking high-impact decisions for one batch review at the end |
| `exec-plan-base` | The plan file format, its on-disk location, and the properties that keep a plan restartable from the file alone |

For work with no tracker Issue behind it. Work that is already a groomed Issue
belongs to the orchestration skills, which keep the same decision split but hold
their record on the Issue instead of a file.

## Installation

Install these skills through the repository's `skills add` workflow documented
in the root README.
