# planning-toolkit

Skills for turning an established direction into delivery work that can be
executed without further shaping.

## Skills

| Skill | Description |
|-------|-------------|
| `planning-toolkit-base` | The shared domain model: Outcome Contract, scope policy plug point, readiness states, tracker mapping, and the handoffs between phases |
| `planning-toolkit-plan` | Cut scope to a finite outcome and register the Project, Milestones, Issues, and dependencies |
| `planning-toolkit-resolve` | Close the research and design blockers a plan left open, then mark the Project ready |
| `planning-toolkit-mvp` | A scope policy, not a phase — the justification standard for proving a hypothesis with the smallest buildable thing |

Planning certifies readiness and names the first unblocked work. Which execution
skill picks that work up is outside this family.

## Installation

Install these skills through the repository's `skills add` workflow documented
in the root README.
