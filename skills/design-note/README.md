# design-note

## Skills

| Skill | Description |
|-------|-------------|
| `design-note` | Write what to build as a short durable note — problem, target, goals, non-goals, and the approach with its reasoning — into a durable Markdown store |

Shallower on *how* than a design doc, and narrower than a product PRD. It expects
the direction to be settled already; shaping an unformed concept is a separate
kind of session.

Requires `workflow-adapter-markdown` and an installed durable Markdown provider.

## Installation

Install these skills through the repository's `skills add` workflow documented
in the root README.
