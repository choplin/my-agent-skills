# design-note

## Skills

| Skill | Description |
|-------|-------------|
| `design-note` | Write what to build as a short durable note — problem, target, goals, non-goals, and the approach with its reasoning — straight into the llm-wiki knowledge base |

Shallower on *how* than a design doc, and narrower than a product PRD. It expects
the direction to be settled already; shaping an unformed concept is a separate
kind of session.

Requires the llm-wiki skills to be installed; the note is written through them.

## Installation

Install these skills through the repository's `skills add` workflow documented
in the root README.
