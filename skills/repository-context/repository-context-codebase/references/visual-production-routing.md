# Visual production routing

Use this reference after the documentation workflow has established what a
visual must communicate, the evidence it must preserve, and where it belongs.
Select the smallest maintainable production path that fits the repository and
the visual's job.

## Select the path

- **Text-native diagram** — author it with the repository's established diagram
  syntax when relationships or flow can be expressed clearly in source text.
  Keep it with the document and verify that its renderer and links work.
- **Existing visual source** — preserve its current source format and use the
  matching available tool or skill. Do not convert an established asset to Pen
  merely to standardize production.
- **New editable designed visual** — apply `repository-context-pen-design` for
  an illustration, composed overview, comparison, or diagram whose visual
  design benefits from editable source and design exploration.
- **Real product or implementation evidence** — apply `showcase-capture-plan`
  and its routed capture skill when the visual must show actual interface state,
  terminal output, or another observable result. Pass the unchanged capture to
  a design workflow only when the approved composition needs one.
- **Annotation or framing** — apply the appropriate showcase annotation skill
  when the source evidence already exists and only explanatory overlays or
  presentation framing are needed.

Follow an established repository convention when it already determines the
path. If no available route can preserve the required evidence or maintainable
source, leave the relationship in prose and report the unresolved visual need
rather than improvising an asset.

## Preserve the handoff

The codebase-documentation workflow owns the audience, message, evidence,
placement, and final integration. The selected production workflow owns its
creation mechanics, approvals, source format, and export. On return, verify the
rendered result in the document and keep the source beside the documentation or
at the repository's established asset location.
